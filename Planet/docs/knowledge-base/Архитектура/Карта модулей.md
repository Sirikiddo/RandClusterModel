# Карта модулей

## Активные директории

| Каталог | Назначение |
|---|---|
| `core/` | entry point и выбор Planet/Contributor |
| `ui/` | Qt window/widget/panels, HUD и render overlay |
| `controllers/` | camera, input orchestration, scene state, A* |
| `dag/` | facade, terrain/path/scene backends, serialization, benchmark |
| `generation/` | terrain/climate/noise и генераторы мешей |
| `model/` | dual-sphere domain model, asset loaders, ore и placement helpers |
| `ECS/` | runtime entity-component storage и animation update |
| `renderers/` | OpenGL upload/render passes, tessellation, particles |
| `contributor/` | процедурный tree asset sandbox и particles |
| `resources/` | shaders, OBJ/MTL/textures |
| `third_party/ProcessDAG/` | встроенный DAG runtime |
| `tests/` | QtTest ECS smoke и DAG benchmark test |

## Альтернативные или частично подключённые подсистемы

- `scene/` — объектно-ориентированный `SceneGraph`/`scene::Entity` с collider/light/body. Компилируется, но основной Planet runtime использует `ECS/`, а не этот graph.
- `culling/TerrainCulling` — самостоятельный culler полного `TerrainMesh`. Основной renderer вместо него вызывает похожую логику в `HexSphereSceneController::getVisibleIndices()`.
- `model/OreSystem` — создаётся после ручной регенерации через `QTimer::singleShot`, но его `update()` не вызывается.
- `dag/DataAdapters` и `tools/converters/DataAdapters` — в проекте есть две adapter-зоны; terrain generator использует `dag/DataAdapters.h`.
- `core/EngineFacade.h` и `core/DebugOverlay.h` — тонкие/старые объявления; активная реализация facade находится в `dag/`.

## Точки расширения

- Новый terrain generator: реализовать `ITerrainGenerator`, добавить индекс в factory/normalizer и UI combo.
- Новый DAG-derived output: поле schema → executor → `SceneDagResult` → обязательное применение в `InputController`.
- Новая ECS-модель: `Mesh::meshId`, loader/handler, ветка `EntityRenderer::renderEntities`.
- Новый render pass: специализированный renderer и явная позиция в `HexSphereRenderer::renderScene`.
