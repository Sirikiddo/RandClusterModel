# Индекс исходников

## Entry/UI

- [core/main.cpp](../../../core/main.cpp) — режим benchmark или GUI, OpenGL format.
- [core/AppViewConfig.h](../../../core/AppViewConfig.h) — Planet/Contributor compile-time switch.
- [ui/MainWindow.cpp](../../../ui/MainWindow.cpp) — команды, toolbar, settings wiring.
- [ui/HexSphereWidget.cpp](../../../ui/HexSphereWidget.cpp) — Qt/OpenGL lifecycle, timers, HUD/panel.
- [ui/PlanetSettingsPanel.cpp](../../../ui/PlanetSettingsPanel.cpp) — generator/params/visual signals.

## Controllers/domain

- [controllers/InputController.cpp](../../../controllers/InputController.cpp) — input, picking, commands, ECS, DAG integration.
- [controllers/HexSphereSceneController.cpp](../../../controllers/HexSphereSceneController.cpp) — topology/terrain/tree/selection/culling state.
- [controllers/PathBuilder.cpp](../../../controllers/PathBuilder.cpp) — graph, costs, A*, spherical polyline.
- [controllers/CameraController.cpp](../../../controllers/CameraController.cpp) — view/projection/rays.
- [model/HexSphereModel.cpp](../../../model/HexSphereModel.cpp) — icosphere и dual cells.
- [model/SurfacePlacement.h](../../../model/SurfacePlacement.h) — единая height-aware surface position.

## DAG/backend

- [dag/EngineFacade.cpp](../../../dag/EngineFacade.cpp) — facade terrain/path/scene.
- [dag/TerrainBackendSelector.h](../../../dag/TerrainBackendSelector.h) — active backend alias.
- [dag/TerrainBackendContract.h](../../../dag/TerrainBackendContract.h) — bridge и concept.
- [dag/DagTerrainBackend.cpp](../../../dag/DagTerrainBackend.cpp) — terrain graph/executor.
- [dag/LegacyTerrainBackend.cpp](../../../dag/LegacyTerrainBackend.cpp) — direct scene backend.
- [dag/DagPathBackend.cpp](../../../dag/DagPathBackend.cpp) — persistent path graph runtime.
- [dag/DagSceneBackend.cpp](../../../dag/DagSceneBackend.cpp) — guarded derived nodes и caches.
- [dag/TerrainSerialization.cpp](../../../dag/TerrainSerialization.cpp) — snapshot JSON.
- [dag/DagBackendBenchmark.cpp](../../../dag/DagBackendBenchmark.cpp) — comparison/CSV.
