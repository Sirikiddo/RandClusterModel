# Постройки и сущности

## Placement panel

Левая overlay-панель внутри `HexSphereWidget` содержит Factory, Mine, Delete. Панель схлопывается двумя синхронными `QVariantAnimation` ширины по 220 мс с `OutCubic`.

Выбор кнопки переключает `InputController::PlacementModel`. Одновременно checked может быть только один режим.

## Где разрешено строить

`refreshBuildPreview()` ищет Explorer с mesh `car` или `pyramid`, берёт соседей его текущей клетки и оставляет только незанятые ECS-сущностями. Эти клетки outline-ятся. Строительство запрещено:

- вне preview;
- на занятой клетке;
- по entity hit;
- при невалидном cell id.

Деревья не учитываются в `isCellOccupied`: здание может появиться на клетке с tree placement.

## Создание

Factory/Mine — обычная ECS entity с `currentCell`, `Mesh`, `Transform=computeSurfacePoint` и sphere collider. Scene DAG получает model request, вычисляет placement, но result не применяется. Renderer сам снова вычисляет position из cell.

## Удаление

Delete mode удаляет только mesh id `factory`/`mine`; Explorer защищён. Можно кликнуть collider здания или terrain cell под ним. Клавиша Delete удаляет любую выбранную entity по отдельной command-ветке, включая Explorer — это отличается от Delete placement mode.

## Статичность

Factory и Mine отклоняются в `isMovableEntity`; клик по клетке при выбранном здании не перемещает его. Их orientation использует surface normal и сохранённый transform forward, обычно default tangent.
