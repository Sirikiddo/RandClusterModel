# Каталог анимаций

| Анимация | Механизм | Статус runtime |
|---|---|---|
| Движение машины | ECS `MoveTo`, polyline sampling | Активна |
| Поворот машины | tangent forward, ограничение 540°/с | Активна |
| Колёса машины | world displacement / radius | Активна |
| Path line | статический GL_LINE_STRIP | Показывается, сама линия не анимирована |
| Foliage sway | vertex shader `uWindTime` | Активна, fixed +0.016/frame |
| Tree particles Planet | point shader time | Активна визуально; CPU wind отключён |
| Contributor particles | CPU spring/wind + point shader | Активна только Contributor mode |
| Factory steam | GL points + elapsed-time shader | Активна |
| Mine cart | cosine ping-pong 4.6 с | Активна при успешном распознавании submesh |
| Water waves | water shader `uTime` | Активна; общий animation timer продвигает time |
| Рудные жилы | Статический fragment-shader FBM + отдельный vertex attribute | Активны; `O` переключает uniform без rebuild |
| Placement panel | 2× QVariantAnimation width, 220 мс | Активна |
| ECS Bounce/Rotate/Scale enum | component types | Не реализованы как отдельные update branches |

## Таймеры и time sources

- ECS: реальный `QElapsedTimer`, dt clamp 0.033, tick около 16 мс.
- Frame facade: paint dt clamp 0.1.
- Foliage и particles: фиксированное +0.016 на render, поэтому скорость зависит от FPS.
- Steam/mine cart: wall elapsed time.
- Water: `waterTime_` продвигается через `animationTimer_ → advanceWaterTime(dt)` примерно каждые 16 мс.
- UI panel: Qt animation clock.

## Руда

Текущая визуализация руды намеренно статична: отдельный `TerrainMesh::ore` передаёт density/type в fragment shader, а FBM строит жилы из world position. Toggle `O` меняет `uOreVisualizationEnabled` и действует в следующем кадре без rebuild. Старые CPU animation/OreSystem paths отключены. История и полный pipeline: [[Руда — старая и текущая реализация]].

## Вода

`HexSphereWidget::animationTimer_` использует измеренный dt, вызывает `advanceWaterTime(dt)` и планирует новый кадр. `InputController::render()` передаёт накопленный `waterTime_` в lighting context, откуда `WaterRenderer` обновляет `uTime`. Отдельный `waterTimer_` для этого не нужен.
