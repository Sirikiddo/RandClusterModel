# Машинка, деревья и модели

## Машинка

Asset: `resources/car/scene.obj` + MTL/textures. `CarModelHandler` парсит object/material groups в submeshes, определяет wheels по именам, вычисляет:

- center и radius каждого wheel;
- average wheel radius;
- local spin axis;
- local alignment по четырём wheel centers.

Renderer ставит машину на terrain surface +0.025 radial offset, применяет surface basis, alignment и scale 0.035. Selected entity дополнительно scale ×1.2.

Wheel rotation не зависит напрямую от animation progress: он основан на displacement между кадрами. Это сохраняет визуальную скорость колёс при biome-dependent movement.

## Factory

Asset `resources/factory/scene.obj`, специализированный `FactoryModelHandler`, scale 0.008 и radial offset -0.04. Используется factory shader. Дополнительный steam pass рисует 16 GL points от жёстко заданного emitter в local coordinates; shader по `QElapsedTimer` делает подъём, swirl и drift.

## Mine

Asset `resources/mine/stylized_gold_mine.obj`, scale 0.008, offset -0.005. `MineModelHandler::finalizeCartAnimation` эвристически ищет submeshes вагонетки по имени `obj2`, bounds и entrance zone. На draw вагонетка ping-pong перемещается по вычисленной inward axis с cosine easing, cycle 4.6 с и distance 1.15 local units.

## Деревья: placement

В Planet mode tree placements приходят из DagSceneBackend после upload refresh. Вероятности: Grass 28%, Savanna 16%, Snow 12%, Tundra 8%; другие biomes — 0. Grass даёт 30% fir, cold biomes — fir. Seed комбинирует terrain seed, generator index, subdivision и cell id.

Позиция внутри cell задаётся triangle index и barycentric weights между двумя polygon vertices и centroid. Затем direction нормализуется и поднимается до height surface. Scale зависит от tree type/biome и humidity.

Legacy controller содержит почти тот же генератор, но RNG consumption отличается: один общий `mt19937` против per-cell RNG в DAG. После regeneration legacy placements обычно заменяются DAG placements.

## Деревья: geometry и draw

`buildContributorAsset()` процедурно строит trunk tubes, branch tubes и leaf blobs. В renderer этот mesh переиспользуется как oak/fir; если generation failed, fallback OBJ. Part names `trunk`/`foliage` позволяют задавать отдельные цвета.

Каждое дерево получает surface orientation, random yaw и scale 0.04 (oak) / 0.045 (fir). Vertex shader качает foliage по `uWindTime`; trunk исключается через uniform.

## Particle foliage

Contributor asset также даёт point particles. Для Planet они трансформируются в world для первых 96 placements. В текущем коде `windWeight` принудительно ставится 0, а `renderPlanetTreeParticles` не вызывает physics `update`, поэтому физический spring/wind не действует; остаётся shader-time billboard/shape animation.

В Contributor mode, напротив, particle physics вызывается каждый render с wind/gust/turbulence и spring/damping.
