# Глобальная сферическая решётка и прямая адресация

`model/IcosahedralGrid` задаёт нерекурсивную частотную решётку на единичной сфере. Первичные узлы имеют постоянные целочисленные адреса. Двойственная сетка Вороного вычисляется из первичных треугольников Делоне и отдельно не хранится. Обратное преобразование находит содержащий точку первичный треугольник арифметически, затем определяет клетку двумя проверками стороны бисектора. Обхода соседей, дерева поиска и атласа в этом преобразовании нет.

Ядро подключено к проекту и доступно через `--icosahedral-grid-tests`. По умолчанию сцена использует прежнюю топологию. Переключатель `Geometry: global Voronoi` включает экспериментальную геометрию через адаптер `HexSphereTopology`, который материализует вычисленные вершины и связи для существующих проходов. Независимый переключатель `Buffers: direct write` включает запись в заранее выделенные итоговые массивы. Объём эксперимента и результаты проверки описаны в [задаче](geometry_comparison_task.txt).

## Первичные узлы и двойственность

Пусть A, B, C — единичные вершины исходной грани правильного икосаэдра, n — положительная целая частота. Узел с адресом `(n,face,i,j)` имеет направление

\[
s_{ij}=\frac{(n-i-j)A+iB+jC}{\|(n-i-j)A+iB+jC\|},\qquad i,j\ge0,\quad i+j\le n.
\]

Это непосредственная формула в трёхмерных векторах. Геометрическая метрика далее везде сферическая. Плоские расстояния не определяют границы клеток.

Двойственная клетка узла a — множество единичных x, для которых `x·a >= x·b` для всех остальных первичных узлов b. Действительно, сферическое расстояние равно `acos(x·a)`, а acos строго убывает. Поэтому полный бисектор соседних a, b задаётся уравнением

\[
x\cdot(a-b)=0.
\]

Он является большим кругом, перпендикулярным дуге a–b и проходящим через её середину `normalize(a+b)`. Другие узлы ограничивают этот круг до ребра Вороного. Вершина Вороного для треугольника Делоне a,b,c равна

\[
v=\pm\frac{(b-a)\times(c-a)}{\|(b-a)\times(c-a)\|}.
\]

Выбирается знак с `v·a>0`. Из формулы непосредственно следует `v·a=v·b=v·c`. В частности, равные расстояния не требуют подгонять узлы под плоские гексы: сначала определяются узлы на одной сфере, затем их сферические бисекторы.

Центром клетки здесь называется первичный узел-генератор. Он не обязан совпадать с центром тяжести площади клетки. Вершины дуала также являются центрами описанных окружностей, а не средними трёх узлов.

## Почему глобальный праймал подходит для точного дуала

Ниже приведён вывод для указанной формулы узлов, а не для произвольной сферической триангуляции. При n делениях каждой исходной грани получается `20n²` треугольников и `10n²+2` узлов. Двенадцать исходных узлов имеют степень 5, остальные — 6.

Для доказательства удобно использовать вспомогательную плоскость исходной грани `N·X=h`. Она нужна только для анализа формулы; программа не хранит плоскую решётку или изображение поверхности. При радиусе описанной сферы 1

\[
h^2=\frac{5+2\sqrt5}{15},\qquad h\approx0.7946544723.
\]

На этой грани `h <= ρ=|X| <= 1`. Дифференциал отображения `X -> X/|X|`, ограниченный на плоскость, имеет сингулярные числа `1/ρ` и `h/ρ²`. Его число обусловленности не превосходит `1/h`. Плоский угол 60° поэтому переходит в сферический угол не больше

\[
2\arctan\!\left(\frac{1}{h\sqrt3}\right)=72^\circ<90^\circ.
\]

Направления сторон сферического треугольника являются образами касательных к исходным прямым сторонам, поэтому оценка относится ко всем углам всех малых треугольников и не зависит от n. Хордовые треугольники также остроугольные: единичные направления хорд из a имеют вид `cos(β/2)t_b-sin(β/2)a`, где t_b — касательное направление. Скалярное произведение двух таких направлений положительно, если соответствующий сферический угол острый. Следовательно, центр описанной окружности хордового треугольника лежит внутри него, а его радиальное направление — внутри сферического треугольника.

Остаётся проверить условие Делоне. Положим `g(X)=|X|` на вспомогательной плоскости. Собственные числа её гессиана равны `1/ρ` и `h²/ρ³`, откуда

\[
h^2 I\preceq D^2g\preceq h^{-1}I.
\]

У двух соседних равносторонних треугольников короткая диагональ ромба — общее ребро a–b, длинная — c–d. При общем центре m и `|c-m|²=3|a-m|²` оценки центральных разностей дают

\[
g(c)+g(d)-g(a)-g(b)\ge(3h^2-h^{-1})|a-m|^2>0.
\]

Последнее неравенство следует из `3h³>1`. Это условие строгой локальной выпуклости кусочно-линейного интерполянта g на каждой внутренней стороне. Поэтому интерполянт выпуклый на исходной треугольной грани. Его линейная часть L для любого малого треугольника удовлетворяет `L(X_j)<=|X_j|` во всех остальных узлах грани. Для нормированных узлов это означает, что круг, описанный около малого сферического треугольника, не содержит других узлов этой грани внутри своей меньшей сферической шапки.

Это свойство распространяется на всю сферу. Сетка инвариантна относительно отражения в плоскости каждого исходного ребра. Пусть x принадлежит исходной грани, а узел s находится за одной из её сторон с внутренней нормалью e. Тогда отражённый узел `s'=s-2(e·s)e` тоже принадлежит сетке и

\[
x\cdot s'-x\cdot s=-2(e\cdot s)(e\cdot x)\ge0.
\]

Для внутренней точки неравенство строгое. Для граничной точки последовательные отражения можно выбирать так, чтобы `N·s` строго возрастало; конечность множества узлов гарантирует попадание в грань без ухудшения расстояния. Следовательно, для x существует ближайший узел в этой грани. Центр описанного круга малого треугольника находится внутри этого треугольника и исходной грани. Пустота его шапки относительно узлов грани поэтому означает пустоту относительно всех узлов. Итак, заданные первичные треугольники являются сферическими треугольниками Делоне.

## Прямое преобразование направления в адрес

### Исходная грань без перебора

Единичные нормали исходных граней пропорциональны вершинам правильного додекаэдра. В ориентации ядра это

\[
(\pm1,\pm1,\pm1),\quad(0,\pm\varphi,\pm\varphi^{-1}),\quad
(\pm\varphi^{-1},0,\pm\varphi),\quad(\pm\varphi,\pm\varphi^{-1},0).
\]

Все имеют длину √3. Для направления q знаки координат сразу выбирают нужные знаки нормалей. После этого достаточно трёх сравнений четырёх выражений

\[
|q_x|+|q_y|+|q_z|,\quad
\varphi|q_y|+\varphi^{-1}|q_z|,\quad
\varphi^{-1}|q_x|+\varphi|q_z|,\quad
\varphi|q_x|+\varphi^{-1}|q_y|.
\]

Тип выражения и знаковые биты индексируют постоянную маленькую таблицу номеров граней. Выбор максимальной нормали даёт грань, пересекаемую радиальным лучом: расстояние до её плоскости вдоль луча равно `h/(N·q)`. Перебора 20 граней в `locate` нет.

### Первичный треугольник из целых частей

Для выбранных A,B,C решается линейное разложение `q=αA+βB+γC`. Коэффициенты — скалярные произведения с заранее известным двойственным базисом. Например,

\[
\alpha=\frac{q\cdot(B\times C)}{A\cdot(B\times C)}.
\]

Однородные координаты `u=nβ/(α+β+γ)`, `v=nγ/(α+β+γ)` нужны только для целочисленной адресации. Они инвариантны к длине входного направления.

Положим `i=floor(u)`, `j=floor(v)`, `r=u-i`, `s=v-j`. При `r+s<=1` содержащий точку треугольник имеет адреса

`(i,j), (i+1,j), (i,j+1)`.

В противном случае его адреса

`(i+1,j), (i+1,j+1), (i,j+1)`.

На внешней стороне исходной грани выбирается один из существующих инцидентных треугольников. На общем ребре выбор стороны не меняет геометрический результат, кроме допустимого выбора владельца равноудалённой границы.

### Клетка по двум сторонам бисекторов

Обозначим единичные вершины найденного треугольника a,b,c. В остроугольной выпуклой триангуляции каждый сферический треугольник пересекает только три клетки Вороного своих вершин. Поэтому принадлежность клетки определяется следующей кусочной формулой:

\[
\operatorname{cell}(q)=
\begin{cases}
a,&q\cdot(a-b)\ge0\ \text{и}\ q\cdot(a-c)\ge0,\\
c,&q\cdot(a-b)\ge0\ \text{и}\ q\cdot(a-c)<0,\\
b,&q\cdot(a-b)<0\ \text{и}\ q\cdot(b-c)\ge0,\\
c,&q\cdot(a-b)<0\ \text{и}\ q\cdot(b-c)<0.
\end{cases}
\]

На каждом пути выполняются две проверки. Это определение сектора внутри уже вычисленного треугольника, а не обход кольца соседей. Утверждение о трёх инцидентных клетках и точности такого преобразования доказано в §3.4, теореме 3, работы Griffith, Koutek, Post (2007), указанной ниже.

В double знак проверяется устойчивой эквивалентной формой

\[
(a-b)\cdot(2q-a-b)=|q-b|^2-|q-a|^2.
\]

Для идеальных единичных узлов это `2q·(a-b)`. Такая запись не вычитает два скалярных произведения, близких к 1, и лучше сохраняет сторону очень маленькой клетки. На точной границе любое из равноудалённых владений геометрически допустимо; реализация использует фиксированное правило выбора.

## Адреса на швах и хранение

Плотные ID не требуют таблицы всех клеток. Сначала нумеруются 12 исходных вершин, затем `30(n-1)` внутренних узлов исходных рёбер, затем `20(n-1)(n-2)/2` внутренних узлов граней. Координата на общем ребре отсчитывается в направлении увеличения номера исходной вершины. Каноническим владельцем служит исходная грань с наименьшим номером.

Соседство и инцидентные треугольники выводятся из шести целочисленных сдвигов и постоянных таблиц исходного икосаэдра. `cell()` вычисляет до шести двойственных вершин по требованию. Размер самого объекта `IcosahedralGrid` не зависит от числа узлов. Пользовательские поля рельефа можно хранить по плотным ID; второй независимый набор геометрических данных не нужен.

`locateRay` принимает луч в локальных координатах планеты и возвращает адрес первого неотрицательного пересечения с базовой сферой. Преобразование камеры и поворота планеты выполняет вызывающий код. Поиск первого видимого пересечения с неровным рельефом остаётся отдельной задачей.

## Проверка реализации

`--icosahedral-grid-tests` сравнивает прямой адрес с независимым полным перебором угловых расстояний. Проверяются швы, обе стороны бисекторов, вершины, ровно 12 пятиугольников, взаимность соседства, пустые сферические шапки, равные расстояния на двойственных рёбрах, ID без пропусков, частоты вплоть до 2²⁰ и пересечения лучей. Частота не обязана быть степенью двойки.

Тесты проверяют численную реализацию; основанием отсутствия обхода соседей служат условия выпуклости и остроугольности, выведенные выше. Эти условия нужно заново проверять при изменении формулы расположения первичных узлов.
